# 跨屏输入

把手机里的文字，直接"打"进内线电脑（不能插 U 盘、不能联网的电脑也能用）。

**核心思路**：电脑上跑一个本地小服务 + 一个网页；手机浏览器打开这个网页，输入/粘贴文字点发送，文字就被当作键盘输入打进电脑当前光标处。安卓、iPhone 通用，**手机不用装任何 App**。

---

## 文件

| 文件 | 作用 |
|---|---|
| `cross-input.ps1` | 电脑端全部功能（网页 + 服务器 + 键盘注入），单文件 |
| `start.bat` | 双击启动 |
| `README.md` | 本说明 |

**要求**：Windows 7 及以上，自带 PowerShell 即可。不需要装 Python、不需要联网、不需要管理员权限。

---

## 使用（3 步）

1. **双击 `start.bat`**，黑窗口会显示手机访问地址，例如 `http://192.168.137.1:8765/`
2. **手机连到电脑同一个网络**（二选一，见下）
3. 手机浏览器打开上面的地址 → 在电脑上点一下要输入的位置 → 手机上输入文字，点 **「输入到电脑」**

### 手机怎么连上电脑

| 方式 | 怎么做 | 适用 |
|---|---|---|
| **WiFi / 局域网** | 手机和电脑连同一个 WiFi（或同一路由器网线） | 最省事 |
| **USB 数据线** | 手机插 USB 线 → 手机开「**USB 网络共享 / USB 网络绑定**」（设置 → 网络/热点） | 电脑没 WiFi、不能连内网时 |

- 安卓：设置 → 网络和互联网 → 热点与网络共享 → **USB 网络共享**（打开）
- iPhone：设置 → 个人热点 → **允许其他人加入**（用 USB 线连电脑；Windows 需装过 iTunes/苹果驱动）

USB 方式下电脑会多出一个虚拟网卡，用黑窗口里显示的 `http://192.168.42.xxx:8765/` 地址访问即可。

## 功能

- **输入到电脑**：文字按键盘逐字打进光标处（换行 = 回车，支持中文、英文、emoji）
- **复制到剪贴板**：把文字放进电脑剪贴板，到目标处 Ctrl+V（长文更快更稳）
- **速度**：快 / 中 / 慢（长文本、某些软件选「慢」更稳）

## 常见问题

**手机打不开网页 / 一直转圈**
- 看黑窗口里显示的地址是否完整（含 `http://` 和端口）
- Windows 防火墙拦截：弹窗时选「允许访问」；没弹窗就手动放行——
  `控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙` → 勾选 `Windows PowerShell`（专用 + 公用）
- USB 方式：确认手机端「USB 网络共享」已打开，且用的是**数据线**不是纯充电线
- 换个端口：`start.bat -Port 9000`

**点「输入到电脑」没反应 / 字打到了别的地方**
- 发送前必须**先在电脑上点一下目标输入框**（能看到光标闪烁），文字会打进当前光标处
- 个别软件对模拟按键有限制，改用「复制到剪贴板」+ Ctrl+V

**文字丢字、乱序**
- 速度选「慢」，或直接用「复制到剪贴板」

**想先确认按键注入是否正常**
- 运行 `cross-input.ps1 -SelfTest`：会弹出一个小窗口并自动输入测试文字，不碰你其它窗口

## 安全说明

- 服务只监听本机/局域网，**没有任何加密和密码**，仅建议在隔离内网、临时使用；用完在黑窗口按 `Ctrl+C` 关闭。
- 电脑端不写文件、不联网、不开机自启；手机端网页由电脑本机提供，不经过任何外部服务器。
